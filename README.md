# CV: Ygor Goulart, QA Tester

A bilingual (English / pt-BR) CV that doubles as the system under test of a QA portfolio.
See [docs/plan.md](docs/plan.md), [GLOSSARY.md](GLOSSARY.md) and [docs/adr/](docs/adr/).

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Vite dev server |
| `npm run build` | Type-check and build to `dist/` |
| `npm run lint` | ESLint |
| `npm run test:e2e` | Playwright (builds and previews the site first) |

First time: `npx playwright install`.
